# Contributing to NeedWise

Thank you for helping make budget-conscious shopping more transparent. Open an issue before a large change. For a pull request:

1. Fork the repository and create a focused branch.
2. Run `npm ci`, `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build`.
3. Add tests for behaviour changes and update documentation.
4. Never include credentials, personal data, or unverified product claims.
